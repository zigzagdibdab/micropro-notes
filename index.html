01. Microprocessor-Based Systems & Evolution

Unit 1.1

Microprocessor

A programmable multipurpose silicon integrated circuit (IC) that has computing and decision-making capabilities[cite: 1]. It fetches binary instructions from an external memory unit, decodes them, and executes arithmetic or logic operations on operands[cite: 1].

  • Contains ALU, General Purpose Registers, and Timing/Control Unit[cite: 1].
  • RAM, ROM, and I/O devices must be connected externally via system buses[cite: 1, 93].
  • Classic examples: Intel 4004, 8080, 8085, 8086[cite: 1, 69].

Microcomputer

A complete, standalone computer system designed for personal or industrial use that utilizes a microprocessor as its primary Central Processing Unit (CPU)[cite: 1].

  • Integrates the microprocessor alongside memory (RAM/ROM) and I/O peripheral controllers on a common motherboard[cite: 1].
  • Capable of accepting real-world user inputs and providing human-readable outputs[cite: 1].
  • Classic examples: Desktop PCs, workstations, laptops, industrial SBCs[cite: 1].

Important Topic 1

8085 Pin Diagram & Signal Descriptions

40-Pin DIP Package

The Intel 8085 is an 8-bit NMOS microprocessor housed in a standard 40-pin Dual In-line Package (DIP) that operates on a single +5V DC power supply[cite: 3, 7]. Its 40 pins are logically partitioned into 6 distinct functional categories[cite: 7]:

1. Power & Clock
  • VCC (Pin 40): +5V main power supply[cite: 6, 7].
  • VSS (Pin 20): Ground reference (0V)[cite: 6, 7].
  • X1, X2 (Pins 1, 2): Connected to crystal oscillator (6.144 MHz)[cite: 6, 7]. Internal clock generator divides it by 2 to yield 3.072 MHz[cite: 3, 7].
  • CLK OUT (Pin 37): Output clock used to synchronize system peripherals[cite: 6, 7].
2. Address & Data Bus
  • AD0–AD7 (Pins 12–19): Time-multiplexed lower-order address and bidirectional data bus[cite: 6, 7].
  • A8–A15 (Pins 21–28): Dedicated unidirectional higher-order address bus carrying bits 8–15[cite: 6, 7].
3. Control & Status
  • ALE (Pin 30): Address Latch Enable; positive pulse during T1 indicates AD0–AD7 carries a valid address[cite: 7, 41].
  • RD (Pin 32): Active LOW Read control signal[cite: 6, 7].
  • WR (Pin 31): Active LOW Write control signal[cite: 6, 7].
  • IO/M (Pin 34): HIGH indicates I/O operation; LOW indicates memory operation[cite: 6, 8].
  • S1, S0 (Pins 33, 29): Bus status indicators[cite: 6, 8].
4. Interrupt Signals
  • TRAP (Pin 6): Highest priority, non-maskable, edge-and-level triggered[cite: 6, 13, 14].
  • RST 7.5 (Pin 7): Edge-triggered, maskable interrupt[cite: 6, 13, 14].
  • RST 6.5, RST 5.5 (Pins 8, 9): Level-sensitive, maskable[cite: 6, 13, 14].
  • INTR (Pin 10): General purpose interrupt request[cite: 6, 13, 14].
  • INTA (Pin 11): Interrupt Acknowledge output[cite: 6, 8].
5. DMA & External Signals
  • HOLD (Pin 38): Peripheral requests CPU to release buses[cite: 6, 8, 11].
  • HLDA (Pin 39): Hold Acknowledge; CPU relinquishes control[cite: 6, 8, 12].
  • READY (Pin 35): Synchronization with slow memory/peripherals[cite: 6, 8].
  • RESET IN (Pin 36): Sets PC to 0000H and resets processor[cite: 6, 8, 12].
  • RESET OUT (Pin 3): Resets peripheral devices[cite: 6, 8, 12].
6. Serial I/O
  • SID (Pin 4): Serial Input Data line read via RIM instruction[cite: 6, 8, 15].
  • SOD (Pin 5): Serial Output Data line set via SIM instruction[cite: 6, 8, 15].

Important Topics 2, 3 & 4

Internal Architecture & Functional Block Diagram

8-Bit Harvard/Von-Neumann

The internal architecture of Intel 8085 is centered around an 8-bit internal bi-directional data bus that ties together arithmetic computation, temporary storage registers, instruction decoding, and memory bus interfacing[cite: 4].

Functional Block Diagram of Intel 8085 Vector Block Scheme

Breakdown of Core Functional Units

1. Accumulator (Register A)

An 8-bit special-purpose register directly coupled with the ALU[cite: 4, 10]. It holds one of the operands for virtually all arithmetic and logical operations and automatically stores the final result computed by the ALU[cite: 4, 10].

2. Arithmetic & Logic Unit (ALU)

Performs binary addition, subtraction, logical AND, OR, XOR, complement, left/right rotate, and comparisons[cite: 4, 20, 21, 22]. It accepts 8-bit operands from the Accumulator and Temporary Register and updates the Flag register accordingly[cite: 4, 5].

3. General Purpose Registers (GPRs)

Six 8-bit registers (B, C, D, E, H, L)[cite: 4, 10]. They can be addressed individually for 8-bit operations or combined into 16-bit register pairs: BC, DE, and HL[cite: 4, 10]. The HL pair serves as the primary data pointer (memory pointer M)[cite: 18].

4. Program Counter (PC) & Stack Pointer (SP)

Both are 16-bit special purpose pointers[cite: 3, 10]. PC holds the memory address of the next sequential instruction byte to be fetched and automatically increments[cite: 4, 10]. SP points to the current Top of Stack location in R/W memory (decrements on PUSH, increments on POP)[cite: 5, 12].

5. Instruction Register & Decoder

When an opcode is fetched from memory, it is loaded into the 8-bit Instruction Register[cite: 5, 10]. The Instruction Decoder then interprets the bit pattern and issues control directives to the Timing and Control Unit to carry out execution[cite: 5].

6. Temporary & W/Z Registers

8-bit non-programmable internal registers[cite: 5, 10]. W and Z hold 16-bit operand addresses during instruction execution (such as CALL or XCHG) without overwriting user-accessible general purpose registers.

Important Topic 5

Bus Structure & Address/Data Demultiplexing

74LS373 Octal Latch

The 8085 requires 16 address lines to address 216 = 64 KB of memory space, and 8 data lines to transfer 8-bit data bytes[cite: 3]. To conserve IC pins and fit inside a standard 40-pin package, Intel time-multiplexed the lower 8 bits of address with the 8-bit data bus onto pins 12–19 (AD0–AD7)[cite: 7, 80].

Step 1: Clock T1

At the start of every machine cycle, the 8085 puts the lower-order address (A0–A7) on AD0–AD7 and pulses ALE = 1 (HIGH)[cite: 41, 42].

Step 2: Latching Address

ALE is connected to the Enable pin (G) of an external 74LS373 Octal D-latch. When ALE drops to LOW, the latch freezes and preserves the lower address A0–A7 for the rest of the cycle[cite: 80].

Step 3: Clocks T2–T4

AD0–AD7 lines are freed to transmit or receive bidirectional 8-bit data (D0–D7) while memory receives the complete 16-bit address (A15–A8 from CPU + A7–A0 from latch)[cite: 41, 42].

8-Bit Register

The 8085 contains an 8-bit flag register consisting of five 1-bit flip-flops that are automatically set (1) or reset (0) according to the arithmetic or logical result produced in the Accumulator[cite: 5, 9]. Three bits are unused and held as don't cares (X)[cite: 9].

Sign Flag (S - Bit D7):

Set to 1 if bit D7 of the result is 1 (negative result in 2's complement notation). Reset to 0 if positive[cite: 9].

Zero Flag (Z - Bit D6):

Set to 1 if the entire 8-bit accumulator result is 00H[cite: 10]. Reset to 0 if non-zero[cite: 10]. Essential for comparison loops[cite: 10].

Auxiliary Carry Flag (AC - Bit D4):

Set to 1 if a carry is generated out of bit D3 into bit D4 (lower nibble to upper nibble)[cite: 10]. Used exclusively by the DAA instruction for BCD arithmetic[cite: 10, 21]. Not directly testable by jump instructions.

Parity Flag (P - Bit D2):

Set to 1 if the accumulator result contains an even number of 1's (Even Parity)[cite: 10]. Reset to 0 for odd parity[cite: 10].

Carry Flag (CY - Bit D0):

Set to 1 if an arithmetic addition generates an overflow carry out of bit D7, or if a subtraction requires a borrow[cite: 10]. Acts as a borrow flag in subtraction[cite: 21].

Instruction Cycle, Machine Cycles & Timing Diagrams

T-States & Bus Cycles

Instruction Cycle (IC)

The total time required by the CPU to fetch, decode, and execute a complete instruction[cite: 39]. One IC consists of 1 to 5 Machine Cycles[cite: 39].

Machine Cycle (MC)

The time required to perform one external bus access operation (e.g., Opcode Fetch, Memory Read, Memory Write, I/O Read, I/O Write)[cite: 40].

T-State

One subdivision of an operation corresponding to exactly one clock period: T = 1/f[cite: 40]. At 3.072 MHz, 1 T-state ≈ 325.5 nanoseconds[cite: 3, 40].

Important Topic 6

Addressing Modes of Intel 8085

5 Modes with Examples

The term Addressing Mode refers to the method by which the operand (data) of an instruction is specified[cite: 17]. The 8085 supports 5 addressing modes[cite: 17]:

1. Immediate Addressing

The 8-bit or 16-bit operand is specified directly within the instruction itself[cite: 17]. Instructions containing the letter 'I' belong to this mode[cite: 17].

MVI A, 45H  ; 2 bytes (3E 45)
LXI H, 2050H ; 3 bytes (21 50 20)[cite: 17]
2. Register Addressing

The operands are contained within CPU general purpose registers (A, B, C, D, E, H, L)[cite: 17]. Data movement occurs entirely inside the processor without memory bus read/write cycles[cite: 17].

MOV A, B   ; 1 byte (78H)[cite: 16, 17]
ADD C      ; 1 byte (81H)[cite: 17, 20]
3. Direct Addressing

The exact 16-bit memory address where the operand is stored is explicitly embedded as bytes 2 and 3 of the instruction[cite: 18].

LDA 2050H  ; 3 bytes (3A 50 20)[cite: 18]
STA 3000H  ; 3 bytes (32 00 30)[cite: 18, 50]
4. Register Indirect Addressing

The memory address of the operand is held in a register pair (primarily the HL pair acting as memory pointer 'M')[cite: 18].

MOV A, M   ; Read from addr in HL[cite: 18]
LDAX B     ; Read from addr in BC[cite: 18, 20]
5. Implied / Implicit Addressing

The operand is implicitly defined within the opcode itself[cite: 18]. No additional register or memory operand is specified[cite: 18]. Most are 1-byte instructions operating on the Accumulator or Carry flag[cite: 18].

CMA        ; 1's complement Accumulator[cite: 18, 22]
RLC        ; Rotate Accumulator Left[cite: 22]
CMC        ; Complement Carry Flag[cite: 18, 22]

8085 Instruction Set Classification

74 Base Mnemonics

1. Data Transfer Group

Transfers data between registers, or between memory locations and registers without altering flag registers[cite: 19].

MOV Rd, Rs | MVI R, data | LXI Rp, data16 | LDA addr | STA addr | LHLD addr | SHLD addr | XCHG[cite: 19, 20]

2. Arithmetic Group

Performs 8-bit or 16-bit addition, subtraction, increment, decrement, and decimal adjustments. Modifies flags[cite: 20].

ADD R | ADC R | ADI data | SUB R | SBB R | SUI data | INR R | DCR R | INX Rp | DCX Rp | DAD Rp | DAA[cite: 20, 21]

3. Logical Group

Performs bitwise logic operations, comparisons, rotations, and carry manipulation[cite: 21, 22].

ANA R | ANI data | ORA R | ORI data | XRA R | XRI data | CMP R | CPI data | RLC | RRC | RAL | RAR | CMA[cite: 21, 22, 23]

4. Branching Group

Alters the normal sequential execution by loading new target addresses into the Program Counter conditionally or unconditionally[cite: 23].

JMP / JNZ / JZ / JNC / JC | CALL / CNZ / CZ / CNC / CC | RET / RNZ / RZ / RNC / RC | PCHL[cite: 23, 24, 25]

5. Stack, I/O & Machine Control

Controls hardware pins, stack operations, interrupt masks, and processor halting[cite: 26].

PUSH Rp | POP Rp | XTHL | SPHL | IN port | OUT port | EI | DI | SIM | RIM | NOP | HLT[cite: 26, 27]

Stacks, Subroutines & Delay Loops

LIFO Structure

Stack Operations: PUSH and POP

The stack is a Last-In First-Out (LIFO) read-write memory structure[cite: 12]. The 16-bit Stack Pointer (SP) points to the current Top of Stack[cite: 12].

  • PUSH B: SP decrements by 1, stores register B[cite: 26]. SP decrements by 1 again, stores register C[cite: 26]. Total SP change = -2[cite: 26].
  • POP B: Copies data at [SP] into C, increments SP by 1[cite: 26]. Copies data at [SP] into B, increments SP by 1[cite: 26]. Total SP change = +2[cite: 26].

Software Delay Calculation

Software delays are created using down-counter loops[cite: 32]. Total time delay is governed by the number of T-states multiplied by clock period T:

; 8-Bit Delay Loop Routine[cite: 32, 33]
      MVI B, FFH    ; 7 T-states
LOOP: DCR B         ; 4 T-states[cite: 33]
      JNZ LOOP      ; 10 T (jump) / 7 T (exit)[cite: 33]
Delay = (7 + 255 × 14 - 3) × (1 / 3.072 MHz) ≈ 1.16 ms

5-Mark Questions Bank (With In-Depth Answers)

Standard Exam Format

Q1 [5M]: Explain why the address and data bus are multiplexed in the 8085 microprocessor and describe how they are demultiplexed with a neat schematic.

Answer:

1. Reason for Multiplexing: The 8085 operates with a 16-bit address bus (A0–A15) and an 8-bit data bus (D0–D7)[cite: 3]. If all 24 lines had separate physical pins along with control, power, and clock pins, the IC would exceed 40 pins[cite: 7]. To minimize pin count, reduce physical package size, and decrease production costs, Intel time-multiplexed the lower-order 8 bits of address with the 8 data lines onto pins 12–19 (AD0–AD7)[cite: 6, 7, 80].

2. Demultiplexing Hardware Circuit: Demultiplexing is implemented using an external 74LS373 Octal D-latch controlled by the 8085's ALE (Address Latch Enable) output signal[cite: 80].

  • During state T1 of every machine cycle, the CPU places the lower byte of the memory address (A0–A7) on AD0–AD7 and pulses ALE HIGH[cite: 41].
  • ALE is connected to the G (Enable) input of the 74LS373 latch[cite: 80]. When ALE drops to LOW at the end of T1, the latch transparently latches and holds A0–A7[cite: 80].
  • During states T2, T3, and T4, the AD0–AD7 lines are freed to act as bidirectional data lines D0–D7, while the 74LS373 continues to provide the lower address A0–A7 to memory[cite: 41, 42].

Q2 [5M]: Define Addressing Modes. Explain the five addressing modes of the 8085 microprocessor with two suitable instruction examples for each mode.

Answer: An addressing mode is the specification method used by an instruction to determine where its operand (data) is stored[cite: 17]. The 8085 has 5 addressing modes[cite: 17]:

  1. Immediate Addressing Mode: Data is specified in the instruction itself[cite: 17].
    • MVI B, 32H: Loads immediate data 32H into B[cite: 16].
    • LXI H, 4000H: Loads 16-bit immediate address 4000H into HL pair[cite: 17].
  2. Register Addressing Mode: Data is transferred between general-purpose registers without memory access[cite: 17].
    • MOV A, C: Copies byte from C to A[cite: 16, 17].
    • ADD B: Adds contents of B to Accumulator[cite: 17, 20].
  3. Direct Addressing Mode: The exact 16-bit memory address is given in bytes 2 and 3 of the instruction[cite: 18].
    • LDA 2500H: Loads byte from memory 2500H into Accumulator[cite: 18, 19].
    • STA 3050H: Stores Accumulator byte into memory 3050H[cite: 18, 19].
  4. Register Indirect Addressing Mode: Memory location is addressed via a register pair pointer (HL, BC, DE)[cite: 18].
    • MOV A, M: Loads data from memory location pointed to by HL pair[cite: 18, 19].
    • STAX D: Stores Accumulator into memory location pointed to by DE pair[cite: 20].
  5. Implied / Implicit Addressing Mode: Operands are implicitly contained in the opcode itself[cite: 18].
    • CMA: Complements the contents of Accumulator[cite: 18, 22].
    • RAL: Rotates Accumulator bits left through Carry flag[cite: 18, 23].

Q3 [5M]: Describe the internal architecture and register organization of the Intel 8085 microprocessor, distinguishing between General Purpose Registers (GPR) and Special Purpose Registers (SPR).

Answer:

1. Architectural Units: The 8085 contains an 8-bit ALU, 8-bit Accumulator, 8-bit Flag register, 8-bit Temporary register, Instruction register & decoder, Timing & Control module, Interrupt control, Serial I/O, and Register Array[cite: 4, 5].

2. General Purpose Registers (GPRs):

  • Consists of 6 eight-bit registers: B, C, D, E, H, L[cite: 4, 10].
  • Used by programmers for general temporary data storage during computation[cite: 4, 10].
  • Can be grouped as 16-bit register pairs: BC, DE, HL[cite: 4, 10]. The HL pair acts as the main memory pointer[cite: 18].

3. Special Purpose Registers (SPRs):

  • Accumulator (A): 8-bit; stores input operands and operation results from the ALU[cite: 4, 10].
  • Program Counter (PC): 16-bit; points to the memory address of the next instruction byte to fetch[cite: 4, 10].
  • Stack Pointer (SP): 16-bit; holds the top memory address of the active LIFO stack[cite: 5, 10].
  • Instruction Register (IR): 8-bit; non-programmable; latches opcodes for decoding[cite: 5, 10].
  • Flag Register: 8-bit; reflects mathematical status (Sign, Zero, Auxiliary Carry, Parity, Carry)[cite: 5, 9, 10].

Q4 [5M]: Draw and explain the step-by-step timing diagram for an Opcode Fetch machine cycle in 8085. What status signals are asserted during this cycle?

Answer: An Opcode Fetch cycle is the first machine cycle of every instruction and takes 4 T-states (or 6 T-states for complex instructions like CALL or DCX)[cite: 40, 41]:

  • Status Assertions: IO/M = 0 (Memory), S1 = 1, S0 = 1[cite: 11, 41]. This combination informs peripherals that an Opcode Fetch is occurring[cite: 11, 41].
  • T1 State: The higher-order address of the instruction (PCH) is placed on A15–A8[cite: 41]. The lower-order address (PCL) is placed on AD0–AD7[cite: 41]. ALE goes HIGH and drops to LOW to latch the address into the external 74LS373[cite: 41].
  • T2 State: The CPU asserts RD = 0 (Active LOW)[cite: 41]. Memory enables its output buffers, placing the opcode byte onto the data bus AD0–AD7[cite: 41].
  • T3 State: The CPU transfers the opcode from the data bus into the Instruction Register[cite: 41]. RD is raised HIGH, terminating the read operation[cite: 41].
  • T4 State: The Instruction Decoder decodes the opcode and prepares the internal control logic for execution[cite: 41]. No external bus activity occurs during T4[cite: 41].

1-Mark Questions & MCQs (With Instant Answers)

Direct Q&A Format
Q1: What is the word length and data bus width of the 8085?

Ans: 8 bits (1 byte)[cite: 3].

Q2: How much total memory space can the 8085 directly address?

Ans: 64 KB (216 = 65,536 bytes) due to its 16-bit address bus[cite: 3].

Q3: What external IC chip is typically used to demultiplex AD0–AD7?

Ans: 74LS373 Octal D-type Transparent Latch[cite: 80].

Q4: What is the operating frequency of the standard Intel 8085A?

Ans: 3.072 MHz (derived from a 6.144 MHz crystal divided by 2)[cite: 3, 7].

Q5: Which interrupt in 8085 is non-maskable?

Ans: TRAP (highest priority, edge and level sensitive)[cite: 6, 13, 14].

Q6: What is the reset address of the 8085 microprocessor?

Ans: 0000H (Program counter is forced to 0000H)[cite: 8, 12, 54].

Q7: How many T-states are required for a standard Opcode Fetch cycle?

Ans: 4 T-states (can extend to 6 T-states for specific instructions)[cite: 40, 41].

Q8: Which flag is used for Binary Coded Decimal (BCD) arithmetic?

Ans: Auxiliary Carry (AC) flag[cite: 10, 21].

Q9: What happens to the Stack Pointer when PUSH is executed?

Ans: The Stack Pointer is decremented by 2 (SP ← SP - 2)[cite: 26].

Q10: What addressing mode is used in MOV A, M?

Ans: Register Indirect Addressing Mode (HL pair acts as memory pointer)[cite: 18].
